# AutoHarness for Codex

A self-maintaining skill library for Codex, inspired by tigerless-labs/autoharness.

## Status

Design in progress. The plugin has not been implemented or released yet.

## Intended capabilities

- Learn reusable instructions from sessions automatically and on demand.
- Validate proposed changes before writing managed skills.
- Consolidate repeated lessons and preserve their evidence.
- Keep project and global libraries separate.
- Provide history, backups, and recovery.
- Support Windows.

## Repository conventions

The primary branch is `master`. Process documents, scratch files, session logs, and local credentials are excluded from this branch.
